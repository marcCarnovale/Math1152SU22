# Mathematics 1152 — Summer 2022

Course materials prepared for an Ohio State University summer offering of Mathematics 1152 (Calculus II).

## Contents

- lecture notes organized by class day;
- homework assignments; and
- exams and practice material.

These files are preserved as teaching materials, not as a software project. They may reflect the pacing, notation, and policies of the Summer 2022 course and should not be treated as current departmental guidance.
